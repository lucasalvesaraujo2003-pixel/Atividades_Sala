# Atividades_Sala
Este repositório contém os códigos em Fortran 90 desenvolvidos para a disciplina de Cálculo Numérico Aplicado. Os ficheiros estão estruturados, modulares e exaustivamente comentados para servir como guia de consulta rápida na prova prática. Este acervo inclui métodos de raízes, sistemas lineares, otimização e equações diferenciais para engenharia.
